# روزا — فروشگاه زیورآلات و اکسسوری 

فروشگاه آنلاین لوکس، مینیمال و دوزبانه (فارسی RTL / انگلیسی LTR) + پنل مدیریت کامل.
بدون هیچ وابستگی npm — فقط `node server.js` (پورت 3000).

## حساب‌های دمو
| نقش | موبایل | رمز |
|---|---|---|
| مدیر | `09120000000` | `admin123` |
| مشتری | `09121112233` | `1234` |

کدهای تخفیف نمونه: `ROZA10` (۱۰٪ حداقل ۱م) · `WELCOME` (۱۰۰هزار تومان) · `PEARL20`

## ساختار
```
server.js        سرور Node بدون وابستگی (API + static) — db.json خودکار از seed ساخته می‌شود
seed.js          داده نمونه: ۱۷ محصول، ۶ دسته، ۵ سفارش، نظرات، FAQ، صفحات، تنظیمات
public/
  index.html     پوسته SPA
  css/app.css    دیزاین‌سیستم (وزیرمتن/Manrope لوکال، RTL/LTR با logical properties)
  js/            i18n · api · ui · shop · admin · main (روتر hash)
  assets/        لوگو، فونت‌ها، تصاویر محصولات/اسلایدر، آپلود رسیدها
```

## مسیرهای فروشگاه
`#/` خانه · `#/shop` فروشگاه (فیلتر/مرتب‌سازی/جستجو) · `#/category/:slug` · `#/product/:slug`
`#/cart` · `#/checkout` · `#/pay/:id` (شبیه‌ساز درگاه) · `#/wishlist` · `#/login` `#/register`
`#/account` · `#/order/:id` (فاکتور + تایم‌لاین) · `#/track` · `#/about` `#/contact` `#/faq` `#/terms` `#/privacy` `#/shipping`

## پنل مدیریت `#/admin`
داشبورد آمار و نمودار ۷روزه · محصولات (تصویر/موجودی/تخفیف/سئو/تنوع) · دسته‌بندی‌ها · سفارش‌ها
(تغییر وضعیت + کد رهگیری + **تأیید/رد رسید کارت‌به‌کارت**) · مشتریان · کدهای تخفیف · اسلایدرها ·
محتوا (نظرات/FAQ/صفحات ثابت) · **تنظیمات سایت** (برند، لوگو، فاویکون، رنگ‌ها، زبان پیش‌فرض،
حالت تعمیرات، درگاه/کد پذیرنده، شماره کارت و شبا، هزینه ارسال و حداقل ارسال رایگان، سئو، فوتر، شبکه‌های اجتماعی)

## جریان پرداخت
- **درگاه بانکی:** ساختار آماده اتصال (نام درگاه + کد پذیرنده در تنظیمات)؛ در دمو شبیه‌ساز نمایشی.
- **کارت‌به‌کارت:** نمایش کارت/شبا ← آپلود رسید + شماره پیگیری ← وضعیت «در انتظار تأیید» ← تأیید/رد مدیر.

## وضعیت‌های سفارش
در انتظار پرداخت ← در انتظار تأیید رسید ← پرداخت شده ← در حال آماده‌سازی ← ارسال شده ← تحویل داده شده / لغو شده
